## 3. Definition of Done

Файл `dod.md`, умов у списку: 6. Скільки закритих історій його проходять,
порахуйте там же, у розділі «Як це працює на практиці» `dod.md`, тут це число не
дублюється.

Що з нього довелось прибрати, щоб він працював на проєкті одного виконавця:
review другою людиною замінено самоперевіркою за списком у день закриття
картки, а інтеграційні тести парсера і перевірку на емуляторах з DoD ЛР2
прибрано, бо результат історій у спринтах це проєктна документація, а не код.
